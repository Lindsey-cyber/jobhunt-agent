# Greenhouse fixtures

SYNTHETIC. These pages were written by hand from the markup that formhand
(MIT, github.com/fdjfnd222dd/formhand, `adapters/greenhouse.js`) documents
for job-boards.greenhouse.io. No real page has been captured into this repo
yet. Replace each with a real capture (`page.content()` saved from a live
application form, personal data scrubbed) as soon as one exists, and keep the
synthetic ones only for cases a real board does not exercise.

| file | case |
|---|---|
| `basic.html` | every required field answerable from the profile |
| `needs-human.html` | a required free-text question and a required salary field |
| `drops-email.html` | `basic.html` whose email input discards the value after it is typed |
