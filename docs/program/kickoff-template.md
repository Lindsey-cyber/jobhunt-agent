# <单元id>：<一句话>

## Goal
候选人的目标（一句话），以及这个单元对目标的贡献。

## Evidence
完成的证据：命令和期望输出，或者真实页面、真实数据上的结果。写不出来，说明这个单元还没切好。

## May write
可以写的路径（必须属于本单元的领域，见 owners.tsv）。

## Must not write
不能写的路径，尤其是共享数据：data/ 下候选人的文件、其他领域的目录。

## Must not do
禁止的动作（例如：提交申请、给雇主发任何东西、登录后抓取、推送到 v3）。

## Budget
token 预算，以及超出预算时怎么办。

## Report
用 PASS / ISSUES / BLOCKED 报告：分支名、head SHA、证据输出原文、偏离任务书的地方。
